# User Guide

## 1. Sign In

- Open LearnBeam
- Sign in using email/password or Google

## 2. Create or Open a Course

- Use the dashboard to create courses
- Open a course to access:
  - Overview
  - Assignments
  - Grades
  - Documents
  - Reminders
  - Activities

## 3. Upload Documents

- Upload syllabi, notes, readings, or study documents
- LearnBeam extracts text and stores it for reuse

## 4. Use Syllabus Import

- Upload a syllabus
- LearnBeam analyzes it and updates course details, assignments, reminders, and grading context

## 5. Use Spark AI

### Course Sources
- Answers from uploaded course documents
- Best for course-specific questions and study support

### Spark Open
- Broader AI help beyond uploaded course files
- Useful for general explanations and study help

## 6. Generate Quizzes

- Use the activities area to generate study quizzes from uploaded course material

## 7. Fact-Check Documents

- Run fact-checking on non-syllabus documents
- Review the saved report and claims summary

## 8. Update Profile

- Upload a profile picture
- Profile changes persist through Supabase-backed storage and profile records
